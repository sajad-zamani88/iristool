Color Palette Generator

          
        

        

          
Pick a base color and a harmony rule — analogous, complementary, triadic, monochromatic or full random — and get five colors spaced correctly around the HSL hue wheel. Every swatch shows its HEX and RGB, copies on click, and the whole set exports as CSS custom properties.

FavIcon Generator

Questions
Asked often, answered plainly.

        ( 02 )
      


      

        How are the palette harmonies calculated?
        
The base color is converted to HSL and moved around the hue wheel: analogous shifts by ±25°, complementary jumps 180°, triadic uses 120° steps, and monochrome keeps the hue while varying saturation and lightness. Random mode rolls five fresh hues with balanced saturation. Saturation and lightness are clamped so nothing comes out invisible.

      

      

        What format does the Favicon Generator export?
        
A 64×64 PNG rendered on a canvas — the format every modern browser accepts via <link rel="icon">. If you need legacy .ico files for very old browsers, run the downloaded PNG through any ICO converter; the pixels are identical.

      

      

        Can I copy the favicon image directly?
        
Yes — the Copy PNG button puts the image on your clipboard wherever the browser supports the image clipboard API (Chrome, Edge, Safari). Everywhere else, use Download .png instead.

      

      

        Is the data I enter saved anywhere?
        
No. IrisTool has no backend and no database. Your colors, glyphs and favicons are rendered entirely inside your browser tab and disappear the moment you close or refresh the page.
