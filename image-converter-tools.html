Questions

Asked often, answered plainly.

( 02 )
Does my image ever leave my device?

No. Upload, conversion and export all happen inside your browser tab using the canvas API. The page has no backend, so there is nowhere for the image to go — not even to a CDN.

What happens to transparency when converting to JPG?

JPG has no alpha channel, so transparent pixels are painted white before encoding. If you need transparency kept, convert to PNG or WebP instead — both preserve alpha.

What does the quality slider do?

It applies to JPG and WebP outputs only — higher quality means bigger files. PNG conversions are always lossless, and ICO embeds a PNG inside the standard ICO container, so neither needs a quality setting.

What is the ICO format exactly?

The classic Windows icon container. Modern ICO files commonly embed a PNG inside the container, which is exactly what this tool produces — a square, contain-fitted image with transparent padding at 16, 32, 48 or 64 px. Browsers accept it via <link rel="icon">.
