Find and Replace

runs in the workbench above

The flagship. As you type in the find box, every match is painted blue in the source — the current one in red — and listed in the match panel with its context. Walk the matches with ▲▼, swap them one at a time for surgical edits, or hit Replace All to change everything at once. Three modes cover every need: Aa for case-sensitive hunts, .* for full regular expressions, and |ab| for whole words only.

Example

The fox crossed the creek. The fox slept. (find: fox → replace: cat)

↓

"The cat crossed the creek. The cat slept." — 2 of the 8 matches in the sample, each one previewed before the swap.

Replace Line Breaks

runs in the workbench above

Turns every line break — \n and Windows \r\n alike — into any string you choose. A space flattens a list into one line; ", " turns it into a sentence; "\t" rebuilds it as columns. The live counter tells you exactly how many breaks are waiting before you press apply.

Example

alpha beta gamma

↓

"alpha, beta, gamma" — three lines folded into one clean list (↵ → ", ").

Use it for flattening listsCSV repairparagraph mergesone-liners

03 / 04

Replace Spaces

runs in the workbench above

Turns every run of spaces into your chosen string. A single space collapses ragged gaps; "_" builds a slug; "," converts a spaced list into CSV. Because it matches runs, not single characters, "word    word" becomes one clean join — never "word,,,,word".

Example

slug this title

↓

"slug_this_title" — every run collapses to a single underscore.

Use it for slug buildingdelimiter swapswhitespace normalisingcolumn alignment

04 / 04

Replace Tabs

runs in the workbench above

Turns every tab character into your chosen string. Four spaces fixes indentation for style guides that demand it; "," converts a pasted spreadsheet row into instant CSV; nothing at all glues the columns together. The counter shows how many tabs hide in your text before you commit.

Example

name email phone

↓

"name,email,phone" — a TSV row becomes CSV in one pass (⇥ → ",").

Questions

Asked often, answered plainly.

( 02 )
Does the find box support regular expressions?

Yes — switch on the .* mode and the find box becomes a full regex engine. Invalid patterns are flagged in red and nothing runs until the pattern is fixed. In plain mode, special characters are escaped automatically, so "a.b" really means the three characters "a.b".

What's the difference between Replace and Replace All?

Replace swaps only the current match — the one painted red — and then advances to the next, which is perfect for selective editing when some matches should stay. Replace All swaps every match in one shot. Both land on the undo stack, so neither is permanent.

How do the quick tools relate to the main one?

They are the same engine with preset patterns: line breaks, runs of spaces, and tabs. Type the replacement string — the preview chip shows exactly what you typed, with ␣ for spaces and ⇥ for tabs — hit apply, and the result lands in the same editor and on the same undo stack as the main tool.

Is the text I paste saved anywhere?

No. IrisTool has no backend and no database. All searching and replacing runs inside your browser tab and disappears the moment you close or refresh the page. There is nothing to leak, because nothing is ever collected.

Can I use these tools offline?

Yes. Once the page has loaded, every tool on it keeps working offline, because all the logic runs locally in your browser.
