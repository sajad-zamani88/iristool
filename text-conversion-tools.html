HTML to Text

runs in the bench above

Strips a page down to its words. Scripts and styles are removed first, comments next, then every remaining tag — while block elements become line breaks so the reading structure survives. With entity decoding on, &mdash; becomes —, &amp; becomes &, and numeric entities become their characters.

Example

<p>Hello <b>world</b> &amp; friends</p>

↓

"Hello world & friends" — tags gone, entity decoded, nothing lost but the noise.

Use it for web scraping prepemail cleanupCMS exportsreadable archives

02 / 07

Text to HTML

runs in the bench above

The reverse trip, done safely. Every &, < and > is escaped first, so pasted markup can never inject itself; then blank-line-separated blocks become <p> elements and single line breaks become <br>. Turn the wrap off for a bare <br>-joined fragment.

Example

Price < 10 & rising Call "now".

↓

two <p> blocks — every special character safely escaped on the way through.

Use it for blog enginesstatic sitescomment systemsemail templates

03 / 07

Markdown Preview

runs in the bench above

A live rendering engine for the working Markdown subset: headings, bold, italic, inline code, fenced blocks, links, lists, quotes and rules. The right pane shows the rendered result as you type; flip one chip to see the generated HTML source and copy it straight into any page.

Example

# Title **bold** and *italic* and `code`

↓

a rendered H1, bold, italic and a code chip — switch to HTML source to grab the markup.

Use it for README draftsdocumentationforum postsnote review

04 / 07

ASCII Converter

runs in the bench above

Turns text into its numeric code points and back — in decimal, hexadecimal or binary, your choice. Encode shows every character's number; decode accepts space, comma or semicolon-separated values in the selected base. Characters beyond the classic 7-bit table are mapped to their full code points, so nothing is lost on the round trip.

Example

Hi

↓

"72 105" decimal — or "48 69" in hex, "01001000 01101001" in binary.

Use it for protocol workteaching bytesdata inspectionchecksum prep

05 / 07

Unicode Converter

runs in the bench above

Escapes every non-ASCII character into a portable form — \uXXXX for source code, U+XXXX for spec sheets, &#xHH; for HTML — while plain ASCII rides through untouched. Decode is format-blind: it resolves \uXXXX, \u{…}, U+XXXX, hex entities and decimal entities in a single pass, in any mixture.

Example

東京 ✓

↓

"\u6771\u4EAC \u2713" — and decode round-trips \u{1F680}, U+00E9 and &#233; just as happily.

Use it for i18n debuggingJSON escapesentity repairemoji inspection

06 / 07

ROT13 Encoder

runs in the bench above

The classic letter wheel: every letter rotates 13 places, A becomes N, B becomes O, and halfway round the alphabet M becomes Z. Case is preserved, and everything that isn't a letter — digits, punctuation, emoji — rides along untouched.

Example

Hello, World!

↓

"Uryyb, Jbeyq!" — letters swapped, everything else intact.

Use it for puzzle hintsspoiler hidinggeocachinglight obfuscation

07 / 07

ROT13 Decoder

runs in the bench above

The same wheel, spun backwards. Because 13 is exactly half of 26, encoding and decoding are the very same operation — run ROT13 twice and you're home. Paste any rotated text and the original surfaces instantly, letter by letter.

Example

Uryyb, Jbeyq!

↓

"Hello, World!" — encode and decode are one function; the wheel is symmetric.

Use it for solving puzzlesreading spoilersgeocache logsround-trip checks

Questions

Asked often, answered plainly.

( 02 )
Does HTML to Text handle scripts and styles?

Yes. <script> and <style> blocks are removed entirely before the remaining tags are stripped, and HTML comments go too — so no code ever leaks into the reading text.

What Markdown does the preview support?

Headings (# through ######), **bold**, *italic*, `inline code`, fenced code blocks, links, unordered and ordered lists, > blockquotes and --- horizontal rules. It's not a full CommonMark engine — it's the working subset needed for drafts, docs and READMEs, rendered live as you type.

Why does the ASCII converter show numbers above 127?

Because it maps full Unicode code points, not just the 7-bit table. "é" becomes 233 and "東" becomes 26481, so nothing is lost on the round trip. Strict 7-bit ASCII only covers 0–127; everything above it still gets a number, just a bigger one.

Is ROT13 secure?

Not even slightly. It's a fixed letter swap with no key, instantly reversible by anyone who knows the trick — perfect for hiding spoilers and puzzle answers, useless for actual secrets. Think of it as a screen, not a lock.

Is the text I paste saved anywhere?

No. IrisTool has no backend and no database. Every conversion runs inside your browser tab and disappears the moment you close or refresh the page. There is nothing to leak, because nothing is ever collected.

Can I use these tools offline?

Yes. Once the page has loaded, every converter keeps working offline, because all the logic — parser, codecs and cipher wheel included — runs locally in your browser.
