Questions

Asked often, answered plainly.

( 02 )
Which developer tools does IrisTool offer?

94 tools across 19 groups: JSON, XML, HTML, CSS, JavaScript, URL, Base64, JWT, hashing, character encoding, color, timestamps, UUID, regex, cron, escape and unescape, data conversion, CSV and TSV — plus a full 35-tool SEO suite. Each group has its own page listing every tool in it.

Can I use these tools on confidential or production data?

Yes. Because nothing is ever transmitted, logged or stored, confidential payloads, configs and access tokens never leave your device. That's the whole point of the architecture: the code comes to your browser, your data never goes the other way.

Are the developer tools really free?

Yes. Every tool is free with no signup, no usage limits and no premium tier. All computation happens on your device, so there are no server costs to pass on to you.

Why is there no server at all?

Because the tools don't need one. Parsing JSON, hashing strings, encoding Base64 and testing regex are all things JavaScript can do in your tab faster than any round-trip to a server — and with no privacy risk.

Can I use these tools offline?

Once the page has loaded, every tool keeps working offline, because all the logic runs locally in your browser.
