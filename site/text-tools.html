Questions

Asked often, answered plainly.

( 02 )
What text tools does IrisTool offer?

55 tools across 9 groups: text analysis counters, a case converter, cleanup utilities, sorting and reordering, extraction of emails and URLs, find and replace, text generators, comparison and diff, plus conversion and encoding tools. Every group has its own page with all of its tools listed end to end.

Are the text tools really free?

Yes. Every text tool is free with no signup, no usage limits and no premium tier. Because the tools run in your browser there are no server costs per use, so there is nothing to charge you for.

Is my text saved anywhere?

No. IrisTool has no backend and no database. Every tool processes your text inside your own browser tab, and the data disappears the moment you close or refresh the page. There is nothing to leak, because nothing is ever collected.

Do the text tools work on mobile?

Yes. Every page is responsive and works in any modern browser on any device — phone, tablet or desktop. No installation, no app to download.

Can I use these tools offline?

Once the page has loaded, every tool keeps working offline, because all the logic runs locally in your browser.
