Sort Lines A–Z

runs in the workbench above

Puts every line in ascending alphabetical order, comparing case-insensitively so "Apple" and "apple" land together. The sort is stable — lines that compare as equal keep the exact order they arrived in.

Example

banana Apple cherry

↓

Apple · banana · cherry — case never breaks the alphabet.

Use it for word listsname rostersglossariesbibliographies

02 / 06

Sort Lines Z–A

runs in the workbench above

The mirror of A–Z: descending alphabetical order, same case-insensitive and stable rules. Useful when the interesting end of the alphabet should come first — rankings, Z-first directories, reverse indexes.

Example

banana Apple cherry

↓

cherry · banana · Apple — the alphabet, walked backwards.

Use it for reverse directoriesrankingsZ-first indexesdescending lists

03 / 06

Sort Numbers

runs in the workbench above

Sorts lines ascending by the first number found in each one — numerically, not alphabetically, so 2 correctly comes before 10. Negatives and decimals are understood; lines with no digits sink to the bottom in their original order.

Example

10 apples 2 pears 33 figs no number here

↓

2 pears · 10 apples · 33 figs — then "no number here", last.

Use it for ranked listsprices & scoresversion listsleaderboards

Shuffle Lines

runs in the workbench above

Randomizes the order of all lines using the Fisher–Yates algorithm — the gold standard for unbiased shuffling. Every possible ordering is equally likely, and every click deals a fresh hand.

Example

a fixed list of five lines…

a new order every click — no position is ever favored.

Reverse Lines

runs in the workbench above

Flips the order of the lines — the last line becomes the first — while leaving the content of each line completely untouched. The classic fix for logs and exports that arrive newest-last when you need newest-first.

Example

first second third

↓

third · second · first — order flipped, contents intact.

Use it for log filescountdown listsnewest-first feedschronology flips

Reverse Text

runs in the workbench above

Mirrors the entire string character by character — letters, digits, punctuation and line breaks all reversed, so "hello⏎world" becomes "dlrow⏎olleh". Unicode is handled safely, so emoji and accented characters survive the flip.

Example

hello world

↓

"dlrow⏎olleh" — every character mirrored, breaks included.

Use it for palindrome checkspuzzles & gameslight obfuscationstring exercises

Questions

Asked often, answered plainly.

( 02 )
Is the A–Z sort case-sensitive?

No. Lines are compared case-insensitively, so "Apple" and "apple" are treated as equal — and because the sort is stable, equal lines keep their original relative order instead of jumping around unpredictably.

How does Sort Numbers treat lines without numbers?

They sink to the bottom while preserving their original relative order. Each line is ranked by the first number it contains — negatives and decimals included — and any later numbers on the same line are ignored.

Is the shuffle truly random?

It uses the Fisher–Yates algorithm, which produces an unbiased permutation — every possible ordering is equally likely. It draws from Math.random(), which is perfectly fine for raffles, flashcards and test data, but not for cryptography.

Is the text I paste saved anywhere?

No. IrisTool has no backend and no database. All sorting runs inside your browser tab and disappears the moment you close or refresh the page. There is nothing to leak, because nothing is ever collected.

Can I use these tools offline?

Yes. Once the page has loaded, every operation on it keeps working offline, because all the logic runs locally in your browser.
