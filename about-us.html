Our story

Why we built a toolbox with no backend.

( 01 )

Most online tools quietly send everything you type to a server somewhere. We thought that was backwards.

IrisTool started from a simple frustration: every time we needed to format JSON, count words, compress an image or generate a meta tag, we had to trust a random website with our data. A password generator that logs your passwords. An image compressor that keeps your photos. A word counter that tracks what you write.

So we built the opposite. A single, calm, static site where every tool runs entirely in your browser tab. There is no server to send your data to, no database to store it in, and no account system to tie it to. Close the tab and everything you typed is gone — exactly the way it should be.

Today IrisTool ships 278 tools across 5 categories — text, developer, calculators, generators and image tools — all free, all instant, all private. No ads, no popups, no premium tier, no email collection. Just the tool you came for, working the moment the page loads.

What we believe

Four principles behind every tool we ship.

( 02 )
01 / Privacy
✱

Privacy by architecture

We didn't add a privacy policy and call it a day — we removed the parts of the stack that could ever collect data. No backend, no database, no analytics, no accounts. Nothing to leak because nothing ever arrives.

02 / Free
∞

Free, without caveats

All 278 tools are free with no signup, no usage limits, no premium tier and no paywalled features. Because running tools in the browser costs us essentially nothing per user, we can keep everything open forever.

03 / Craft
◈

Small, careful, human

Every tool is hand-built, not auto-generated. We test edge cases, tune keyboard shortcuts, and design for focus — not engagement. IrisTool is meant to feel like a well-organized desk, not a product trying to keep you on the page.

04 / Speed
→

Instant, always

Static pages, zero round-trips, no loading spinners. A tool is ready the moment you land on it — and most keep working offline once loaded, because all the logic lives in your browser.

05 / Calm
◉

Calm by design

No popups, no cookie banners, no newsletter walls, no dark patterns. The interface is quiet on purpose — so you can focus on the work, not the website.

06 / Open
✦

Open to everyone

IrisTool works on any modern browser, on any device, without installation. No platform lock-in, no proprietary formats, no data to export — because there was never any data to begin with.

The privacy promise

Nothing you type here ever leaves this page.

IrisTool has no database and no backend — literally. Every tool is plain JavaScript running inside your browser tab. There is nothing to hack, nothing to leak and nothing to delete, because we never receive your data in the first place.

Is IrisTool really free?

Yes. All 278 tools are free with no signup, no usage limits and no premium tier. There are no servers to pay for per request, so there is nothing to charge you for.

Is my data safe here?

Completely. The site has no backend and no database — every tool runs entirely in your browser. Text you paste and images you open are never transmitted, logged or stored anywhere.

Do I need to create an account?

No account, no email, no tracking cookies. Open any tool and use it immediately — that's the whole idea.

Does it work offline?

Once the page has loaded, most tools keep working offline because all the logic runs locally in your browser.

The journey

From a single word counter to 278 tools.

( 03 )
The spark

A simple word counter, built differently

IrisTool started as a single tool — a word counter that ran entirely in the browser. No tracking, no account, no fluff. It worked the moment the page loaded, and that felt right.

The expansion

From one tool to a full toolbox

One tool became five, then fifty. JSON formatters, image compressors, meta tag generators, BMI calculators — each one built with the same rule: everything must stay in the browser.

Today

278 tools, 5 categories, zero servers

IrisTool now ships text tools, developer tools, calculators, generators and image tools — all free, all private, all running on static pages. The rule hasn't changed: nothing you type ever leaves this page.

What's next

More tools, same philosophy
